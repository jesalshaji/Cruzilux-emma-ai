# CruziLux Engineering Principles

1. The product comes before the code.

2. Every module has one responsibility.

3. Configuration belongs in environment variables.

4. Data should be separated from logic.

5. The best idea wins.

6. If new evidence appears, adapt.

7. Build for today's customer while leaving room for tomorrow's scale.

8. Every feature must solve a real business problem.

9. Every milestone must be demonstrable.

10. Finish before expanding.

11. Question the architecture before questioning the implementation

12. Readable code over clever code.

13. Reusable modules.

14. Configuration over hardcoding.

15. Single responsibility.

16. Documentation before complexity.

17. Measure before optimization.

18. One feature at a time.

19. No duplicated code.

---

> **Build with purpose. Design for people. Scale with principles.**
